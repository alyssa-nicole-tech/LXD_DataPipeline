# LXD_DataPipeline 

This project uses an automated data pipeline to process user experience metrics on engagement, sentiment, and content success from a Learning Experience Platform (LXP). 

Pipeline Details: 

A. The metrics are extracted, transformed, loaded (ETL) into cloud storage containers using Python and SQL scripts.

B. The data is then cleaned and organized within an IDLE environment using Python and SQL scripts. 

C. The data is then used to analyze gaps, needs, engagement, and sentiment for batch of users. 

D. The dataset is analyzed for learning gaps, needs, and engagement trends to enable adaptive improvement of content design.
